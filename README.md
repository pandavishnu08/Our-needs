# Juniper Kitchen

A responsive restaurant ordering front-end built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server.

## Deploy

The GitHub Actions workflow in `.github/workflows/deploy.yml` publishes the site to GitHub Pages whenever a change is pushed to `main`. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**. The deployed URL will appear in the workflow run and in the `github-pages` environment.

The current login and checkout interactions are demo-only and do not process payments or orders.
